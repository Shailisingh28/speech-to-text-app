# Speech To Text App

A backend application built using Spring Boot that supports user authentication and speech-to-text processing.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- Maven

---

## Day 1

- Spring Boot project setup
- MySQL configuration
- User entity creation
- Database connection established

## Day 2

- JWT Authentication implemented
- User Registration API
- User Login API
- Password encryption using BCrypt
- Spring Security configuration
- Added protected APIs
- JWT token validation
- Authentication filter implementation
- Secured endpoints using Spring Security

## Day 3

- Added File Upload API
- Audio file validation implemented
- Supported MP3 and WAV uploads
- File storage service created
- Upload response DTO added
- Tested APIs using Postman

## Day 4

- Integrated AssemblyAI Speech-to-Text API
- Added audio transcription service
- Implemented audio upload to AssemblyAI
- Generated transcript using external API
- Added transcription polling mechanism
- Processed JSON responses using ObjectMapper
- Added transcription status handling
- Returned converted text response to client
- Tested transcription APIs using Postman

## Day 5

### Frontend Development (React + Vite)

Implemented a modern React frontend for the Speech-to-Text application.

### Features Added

- User Registration UI
- User Login UI
- JWT Token Storage
- Protected Dashboard Flow
- Audio File Upload
- Speech-to-Text Transcription Display
- Logout Functionality
- Responsive Bootstrap UI

### Technologies Used
